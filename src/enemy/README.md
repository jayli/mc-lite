# 丧尸敌人系统 (Zombie Enemy System)

## 概述

此功能为游戏添加了丧尸敌人，丧尸具有以下特性：

- 符合我的世界原版风格的视觉外观
- 尺寸为1x1x2方块单位
- 能够检测并追踪玩家
- 具备物理碰撞系统，可以与世界和其他实体互动
- 可以被枪械攻击并消灭

## 特性详情

### 1. 视觉外观
- 方块化的人形模型，模仿我的世界丧尸风格
- 绿色调材质，符合丧尸主题
- 由头、身体、四肢组成的几何结构

### 2. AI行为
- **感知系统**：丧尸有10个方块的感知范围
- **追踪行为**：检测到玩家后会朝玩家移动
- **状态管理**：在idle（静止）和chasing（追击）状态间切换
- **自主行动**：在闲置状态下会有轻微的随机移动

### 3. 物理系统
- 与世界方块的碰撞检测
- 能够上下一级台阶，但无法跳跃
- 与玩家的碰撞检测

### 4. 战斗系统
- 生命值系统（默认100点生命值）
- 受伤反馈（视觉闪烁效果）
- 被消灭后的清理机制

## 使用方法

### 生成丧尸
- 按下 `Z` 键可在玩家附近随机位置生成一个丧尸

### 战斗
- 使用枪械（普通枪或加特林）射击丧尸
- 普通枪每次造成25点伤害
- 加特林每次造成35点伤害
- 丧尸生命值降为0时会被消灭

## 技术细节

### Zombie.js
- 实现了丧尸的视觉表示、AI行为和物理特性
- 包含移动、感知、碰撞检测和战斗逻辑

### ZombieManager.js
- 管理多个丧尸实例的生命周期
- 处理批量更新和性能优化

### Game.js 集成
- 添加了丧尸管理器实例
- 在游戏循环中更新丧尸状态
- 添加了生成丧尸的快捷键（Z键）

## 碰撞检测
丧尸系统与现有物理系统集成，确保丧尸能够：
- 在地形上正确移动
- 避开障碍物
- 与玩家发生碰撞
- 正确响应地形高度变化
