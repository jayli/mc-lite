# Feature Specification: 关闭创造台功能

**Feature Branch**: `019-workbench-close`
**Created**: 2026-03-14
**Status**: Draft
**Input**: User description: "请增加一个功能，关闭建造台的功能，即当建造台开启的状态下，在设置里的"建造台已打开"按钮变成"关闭创造台"，点击后则关闭建造台的功能，关闭后将建造台的方块都删除掉。同时不要破坏原有游戏功能。"

## Clarifications

### Session 2026-03-14

- Q: 当玩家站在创造台上时点击关闭，应该如何处理玩家位置？ → A: 显示警告，不允许关闭直到玩家离开创造台区域（Option C）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 关闭已开启的创造台 (Priority: P1)

作为玩家，当创造台已经开启时，我可以在设置界面中看到"关闭创造台"按钮，点击后能够关闭创造台并清除所有创造台相关的方块，以便释放空间或重新开始建造。

**Why this priority**: 这是核心功能，允许玩家管理创造台的生命周期，释放游戏世界空间，是玩家使用创造台后的必要清理操作。

**Independent Test**: 可以独立测试：开启创造台 -> 打开设置 -> 点击"关闭创造台"按钮 -> 验证创造台方块被清除且按钮状态恢复。

**Acceptance Scenarios**:

1. **Given** 创造台已开启, **When** 玩家打开设置界面, **Then** "创造台已打开"按钮应显示为"关闭创造台"并变为可点击状态
2. **Given** 创造台已开启且设置界面打开, **When** 玩家点击"关闭创造台"按钮, **Then** 创造台的所有方块（包括平台和上面的建造内容）应被删除
3. **Given** 玩家点击"关闭创造台"按钮后, **Then** 按钮文本应恢复为"打开创造台"（或"创建创造台"）且状态变为可点击
4. **Given** 创造台已关闭, **When** 玩家再次打开设置界面, **Then** 应可以重新创建新的创造台

---

### User Story 2 - 保留原有游戏功能 (Priority: P1)

作为玩家，关闭创造台功能不应影响游戏中的其他功能，包括射击、移动、丧尸系统、存档等原有功能。

**Why this priority**: 确保新功能不会引入回归问题，保持游戏的稳定性和一致性。

**Independent Test**: 关闭创造台后，验证其他所有游戏系统（射击、丧尸、存档/读档、设置切换等）仍然正常工作。

**Acceptance Scenarios**:

1. **Given** 玩家关闭创造台后, **When** 进行射击操作, **Then** 枪械系统应正常工作
2. **Given** 玩家关闭创造台后, **When** 与丧尸交互, **Then** 丧尸AI和战斗系统应正常工作
3. **Given** 玩家关闭创造台后, **When** 执行存档操作, **Then** 游戏应能正常保存进度
4. **Given** 玩家关闭创造台后, **When** 调整其他设置（如分辨率、丧尸数量等）, **Then** 设置应正常生效

---

### Edge Cases

- **创造台正在创建时关闭**: 如果创造台正在创建过程中（异步操作），点击关闭应等待创建完成后再执行关闭，或安全地取消操作
- **创造台区域有玩家**: 关闭创造台时，如果玩家站在创造台区域内，系统应显示警告提示"请离开创造台区域后再关闭"，并禁止关闭操作直到玩家离开
- **创造台方块被手动修改**: 如果玩家手动删除了部分创造台方块，关闭功能应仍能正确清理剩余的创造台方块
- **多次点击关闭按钮**: 防止玩家快速多次点击关闭按钮导致重复操作或错误状态
- **游戏存档后读档**: 关闭创造台后执行存档，读档后应正确反映创造台已关闭的状态

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须在创造台已开启状态下，将设置界面中的"创造台已打开"按钮文本变更为"关闭创造台"
- **FR-002**: 系统必须使"关闭创造台"按钮处于可点击状态（非禁用）
- **FR-003**: 当玩家点击"关闭创造台"按钮时，系统必须删除创造台的所有方块，包括平台方块（playground_block, playground_center_block）以及平台上玩家建造的所有方块
- **FR-004**: 关闭创造台后，系统必须将按钮状态恢复为初始状态（显示"创建创造台"并允许点击）
- **FR-005**: 系统必须正确更新创造台的激活状态标记（isPlaygroundActive）为 false
- **FR-006**: 关闭创造台后，系统必须清除创造台方块追踪集合（playgroundBlocks），释放内存
- **FR-007**: 系统必须确保关闭创造台后，导出模型按钮（如存在）应被隐藏或禁用
- **FR-008**: 系统必须保证关闭创造台操作不会破坏或影响游戏中的其他功能（枪械、丧尸、存档、设置等）
- **FR-009**: 当玩家位于创造台区域内时，系统必须显示警告提示，禁止关闭操作直到玩家离开创造台区域
- **FR-010**: 系统应防止重复点击导致的重复操作

### Key Entities *(include if feature involves data)*

- **PlaygroundService**: 创造台服务单例，管理创造台的生命周期和状态
  - `isPlaygroundActive`: 布尔值，标记创造台是否处于激活状态
  - `playgroundOrigin`: 创造台原点坐标（左下角）
  - `playgroundBlocks`: Set，存储所有创造台方块的坐标键值
  - `playgroundSize`: 创造台尺寸（默认40x40）
  - `world`: 游戏世界实例，用于方块操作
- **Settings UI**: 设置界面
  - `btnCreatePlayground`: 创建/关闭创造台按钮
  - `btnExportModel`: 导出模型按钮（创造台开启时显示）
  - `settingsModal`: 设置模态框

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可以在3秒内完成关闭创造台的操作（从打开设置到点击按钮）
- **SC-002**: 关闭创造台后，所有创造台相关的1600个平台方块（40x40）应在1秒内被完全清除
- **SC-003**: 关闭创造台后，100%的其他游戏功能（射击、丧尸、存档、设置切换）应正常工作，无回归问题
- **SC-004**: 用户能够立即在关闭后重新创建新的创造台，创建流程与首次创建完全一致
- **SC-005**: 关闭创造台操作不应导致游戏帧率下降超过10%（保持60fps以上）
- **SC-006**: 关闭创造台后，内存中不再保留已删除方块的引用（无内存泄漏）
