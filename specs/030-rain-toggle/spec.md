# Feature Specification: 下雨功能开关

**Feature Branch**: `030-rain-toggle`
**Created**: 2026-04-02
**Status**: Draft
**Input**: User description: "新增下雨，在配置菜单中增加一个"下雨"的按钮，按下表示开启下雨，弹起表示不下雨。按钮放在TNT破坏方块这个区域，放在"点击开启"的右边。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 开启/关闭下雨效果 (Priority: P1)

玩家在游戏配置菜单中点击下雨按钮，可以切换下雨天气效果的开启状态。

**Why this priority**: 核心功能，是用户需求的主要交付价值。

**Independent Test**: 可以通过点击按钮并观察画面中是否出现雨滴效果来独立验证。

**Acceptance Scenarios**:

1. **Given** 游戏正在运行且配置菜单已打开，**When** 玩家点击"下雨"按钮（当前显示"点击开启"），**Then** 按钮文字变为"点击关闭"，画面中出现下雨效果
2. **Given** 下雨效果已开启，**When** 玩家点击"下雨"按钮（当前显示"点击关闭"），**Then** 按钮文字变为"点击开启"，画面中下雨效果消失
3. **Given** 游戏刚启动，**When** 玩家打开配置菜单，**Then** 下雨按钮显示默认状态（关闭，文字为"点击开启"）

---

### User Story 2 - 下雨效果的视觉反馈 (Priority: P2)

下雨效果开启后，玩家能在游戏画面中看到明显的雨滴视觉效果。

**Why this priority**: 增强用户体验，确保功能不仅是开关，还有实际的视觉表现。

**Independent Test**: 开启下雨后，观察画面是否有雨滴从天空落下。

**Acceptance Scenarios**:

1. **Given** 下雨效果已开启，**When** 玩家观察游戏画面，**Then** 可以看到雨滴从天空向下落下的视觉效果
2. **Given** 下雨效果已关闭，**When** 玩家观察游戏画面，**Then** 画面晴朗，无雨滴效果

---

### Edge Cases

- 下雨效果是否影响游戏性能？下雨期间帧率应保持稳定（下降不超过10%）。
- 下雨效果与日夜交替是否冲突？下雨效果应独立于光照系统，不相互影响。
- 快速连续点击按钮时，状态切换正确响应：采用100-200毫秒防抖机制，防止重复点击导致状态混乱。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 配置菜单中必须在"TNT破坏方块"区域增加一个"下雨"按钮，位置在"点击开启"按钮的右边
- **FR-002**: 按钮必须采用开关样式（按下状态表示开启，弹起状态表示关闭）
- **FR-003**: 按钮点击时必须切换下雨效果的开启/关闭状态
- **FR-004**: 按钮文字必须根据当前状态动态显示："点击开启"（关闭状态）或"点击关闭"（开启状态）
- **FR-005**: 开启下雨时，画面中必须显示雨滴从天空落下的视觉效果
- **FR-006**: 关闭下雨时，雨滴效果必须立即消失
- **FR-007**: 下雨效果的状态必须通过 HUD 消息提示玩家（如"已开启下雨"/"已关闭下雨"）
- **FR-008**: 下雨按钮必须继承现有按钮样式（btn-small btn-status-toggle），保持UI风格统一

### Key Entities

- **RainState**: 下雨效果的状态（开启/关闭），存储在游戏状态中
- **RainEffect**: 下雨视觉效果，包含雨滴的位置、速度（每秒10-15米）、密度（50-100颗）、范围（玩家周围50米半径）等参数

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 玩家可以在配置菜单中找到"下雨"按钮，按钮位于"TNT破坏方块"区域、"点击开启"按钮右侧
- **SC-002**: 点击"下雨"按钮后，状态切换响应时间小于100毫秒，无明显延迟感
- **SC-003**: 开启下雨后，玩家能清晰看到雨滴效果，雨滴数量为50-100颗（稀疏细雨效果），出现在玩家周围50米半径范围内
- **SC-004**: 下雨效果开启/关闭时，HUD 消息正确提示当前状态
- **SC-005**: 按钮样式与现有按钮风格一致，不影响整体UI美观度
- **SC-006**: 下雨效果不会导致帧率下降超过10%

## Clarifications

### Session 2026-04-02

- Q: 雨滴密度与数量应该是多少？ → A: 稀疏（约50-100颗雨滴，细雨效果）
- Q: 雨滴落下速度应该是多少？ → A: 中等速度（约每秒10-15米，真实感）
- Q: 快速连续点击按钮时的行为？ → A: 短防抖（100-200毫秒内重复点击无效）
- Q: 下雨时是否需要音效？ → A: 无音效（仅视觉效果）
- Q: 雨滴出现范围？ → A: 仅玩家周围固定半径（如50米）

## Assumptions

- 下雨效果默认关闭，玩家需要手动开启
- 雨滴视觉效果使用粒子系统实现（类似现有粒子特效）
- 下雨效果独立于其他天气/光照系统，不相互影响
- 雨滴仅是视觉效果，不会影响玩家移动、方块放置等游戏操作
- 下雨效果无音效，仅提供视觉体验（音效可后续迭代添加）
