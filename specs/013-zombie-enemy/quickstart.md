# 快速入门：丧尸敌人系统

**功能**: 丧尸敌人系统
**分支**: 013-zombie-enemy
**日期**: 2026-02-11

## 概述

此功能实现了符合我的世界原版风格的丧尸敌人系统，具有AI追踪、物理碰撞和战斗功能。

## 安装/设置

1. 切换到功能分支：
   ```bash
   git checkout 013-zombie-enemy
   ```

2. 确保项目依赖项已安装（Three.js通过CDN加载）

3. 启动开发服务器：
   ```bash
   npm run start
   ```

## 如何使用

1. 丧尸将在游戏中自动生成或通过控制台命令创建
2. 当玩家进入丧尸感知范围时，丧尸将开始追踪玩家
3. 玩家可以使用枪械攻击并消灭丧尸
4. 丧尸具备物理特性，会与世界进行碰撞检测

## 主要组件

- `src/enemy/Zombie.js`: 丧尸的主要实现，包含渲染、AI、物理逻辑
- 与现有物理系统的集成
- 生命值管理和消灭机制

## API/接口

- Zombie类提供了初始化、更新和渲染方法
- 与玩家的交互接口
- 伤害和消灭事件处理
