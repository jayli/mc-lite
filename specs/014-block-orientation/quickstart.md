# Quickstart: Block Orientation System

**Feature**: 014-block-orientation
**Date**: 2026-02-22

## 概述

本功能为所有可放置方块添加水平朝向属性，实现"移除-放置时顺时针旋转90度"的核心功能。

## 快速开始

### 1. 体验朝向旋转

1. 启动游戏: `npm run start`
2. 选择一个有方向性的方块（如 handrailA 栏杆）
3. 放置方块（默认朝东）
4. 移除该方块
5. 再次放置同类型方块 → 方块顺时针旋转90度（朝南）
6. 重复移除-放置，朝向依次变为西→北→东→南...

### 2. 验证持久化

1. 放置一个带朝向的方块（如朝西的 handrailA）
2. 保存游戏（自动保存或刷新页面触发）
3. 刷新页面重新加载
4. 验证方块仍朝向西

### 3. 验证旧存档兼容

1. 准备一个旧版本存档（方块数据为字符串格式）
2. 加载存档
3. 验证所有方块正常显示，默认朝东
4. 保存存档，验证格式升级为对象类型

## 核心概念

### 朝向枚举

| 值 | 方向 | 旋转角度 |
|----|------|----------|
| 0  | 东 (EAST)  | 0°   |
| 1  | 南 (SOUTH) | 90°  |
| 2  | 西 (WEST)  | 180° |
| 3  | 北 (NORTH) | 270° |

### 放置记忆规则

- **会话内有效**: 放置记忆仅在当前游戏会话有效
- **按类型独立**: 每种方块类型独立记忆
- **默认朝东**: 无移除历史时，新放置方块朝东
- **重置机制**: 重新加载游戏后，放置记忆重置

### 数据格式

```javascript
// 新格式 (推荐)
{ type: "handrailA", orientation: 1 }

// 旧格式 (兼容)
"handrailA"  // 等价于 { type: "handrailA", orientation: 0 }
```

## 关键文件

| 文件 | 职责 |
|------|------|
| `src/utils/OrientationUtils.js` | 朝向枚举和计算工具 |
| `src/world/Chunk.js` | 方块数据存储和渲染旋转 |
| `src/entities/player/Player.js` | 放置记忆逻辑 |
| `src/services/PersistenceService.js` | 存档兼容处理 |

## 性能注意事项

- 旋转通过矩阵变换实现，不增加 Draw Call
- 复用现有 dummy 对象，避免每帧创建新对象
- Face Culling 不受朝向影响
- 后台合并正常工作

## 故障排除

### 问题: 方块朝向没有旋转

**检查**:
1. 确认移除的是同类型方块
2. 确认在当前会话内（刷新页面会重置记忆）

### 问题: 旧存档加载失败

**检查**:
1. 确认存档格式正确（字符串或对象）
2. 检查浏览器控制台是否有错误信息

### 问题: 性能下降

**检查**:
1. 使用 P 键查看性能监控
2. 确认 InstancedMesh 合并正常工作
