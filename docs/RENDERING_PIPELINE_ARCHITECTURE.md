# 渲染管线架构图

本文档描述 mc-lite 项目的渲染管线架构。

## 整体架构概览

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              渲染管线整体架构                                 │
└─────────────────────────────────────────────────────────────────────────────┘

                         ┌───────────────────────┐
                         │      blockData        │ ← 唯一权威数据源
                         │   (区块网格数据层)      │    存储方块位置、类型、朝向
                         │                       │    {"x,y,z": {type, orientation}}
                         └───────────────────────┘
                                    ↑        ↓
                     ┌──────────────┴────────┴──────────────┐
                     │                                     │
             ┌───────┴───────┐                   ┌──────────┴──────────┐
             │   初始生成     │                   │     动态更新        │
             │   (一次性)     │                   │   (玩家交互)        │
             └───────────────┘                   └─────────────────────┘
                     │                                     │
                     ↓                                     ↓
        ┌────────────────────────┐            ┌────────────────────────────┐
        │      WorldWorker       │            │      主线程立即响应         │
        │  ┌──────────────────┐  │            │  · addBlockDynamic()       │
        │  │ 地形生成         │  │            │  · removeBlocksBatch()     │
        │  │ (Perlin噪声)     │  │            │  · 创建动态 Mesh            │
        │  └──────────────────┘  │            │  · 更新 blockData          │
        │  ┌──────────────────┐  │            │  · 更新邻居补面             │
        │  │ 面剔除计算       │  │            │  · dirtyBlocks++           │
        │  │ (6面可见性判定)  │  │            └────────────────────────────┘
        │  └──────────────────┘  │                         │
        │  ┌──────────────────┐  │                         ↓
        │  │ AO 计算          │  │            ┌────────────────────────────┐
        │  │ (环境光遮蔽)     │  │            │    Consolidation 合并      │
        │  └──────────────────┘  │            │  ┌──────────────────────┐  │
        └────────────────────────┘            │  │ 防抖触发              │  │
                     │                        │  │ · 50个方块阈值       │  │
                     ↓                        │  │ · 1000ms 延迟        │  │
        ┌────────────────────────┐            │  └──────────────────────┘  │
        │      渲染数据返回       │            │  ┌──────────────────────┐  │
        │  · d{type: [位置数组]}  │            │  │ 发送 blockData       │  │
        │  · visibleKeys         │────────────→│  │ 到 WorldWorker       │  │
        │  · solidBlocks         │   合并      │  └──────────────────────┘  │
        │  · aoLow / aoHigh      │            │  ┌──────────────────────┐  │
        └────────────────────────┘            │  │ Worker 重算          │  │
                     │                        │  │ 面剔除 + AO          │  │
                     ↓                        │  └──────────────────────┘  │
        ┌────────────────────────────────────────────────────────────────────┘
        │                       InstancedMesh 创建                            │
        │  ┌──────────────────────────────────────────────────────────────┐  │
        │  │  删除所有动态 Mesh                                             │  │
        │  │  为每种方块类型创建 InstancedMesh                              │  │
        │  │  设置 AO 属性 (aAoLow, aAoHigh, aOrientation)                  │  │
        │  └──────────────────────────────────────────────────────────────┘  │
        └─────────────────────────────────────────────────────────────────────┘
                                     │
                                     ↓
                    ┌───────────────────────────────┐
                    │         Three.js 渲染          │
                    │    (高效的批量 Draw Call)      │
                    └───────────────────────────────┘
```

## 数据层关系

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            数据层金字塔                                      │
└─────────────────────────────────────────────────────────────────────────────┘

                            ┌─────────────────┐
                            │    渲染层        │  ← 最顶层：玩家可见
                            │  InstancedMesh  │     可随时重建
                            │   + 动态 Mesh   │
                            └─────────────────┘
                                    ↑ 派生
                            ┌─────────────────┐
                            │    计算层        │  ← 中间层：可重新计算
                            │  面剔除数据      │     visibleKeys, AO数据
                            │  AO 属性        │
                            └─────────────────┘
                                    ↑ 派生
                            ┌─────────────────┐
                            │    数据层        │  ← 基础层：唯一权威源
                            │   blockData     │     持久化存储
                            │  {type, orient} │     所有操作都更新此层
                            └─────────────────┘
```

## 关键数据结构

### blockData (数据层)

```javascript
// Chunk.js 中的核心数据
this.blockData = {
  "x,y,z": {
    type: "dirt",           // 方块类型
    orientation: 0          // 方块朝向 (0-5)
  }
}

// 辅助数据
this.solidBlocks = new Set(["x,y,z", ...])  // 实心方块集合
this.instanceIndexMap = new Map()            // 实例索引映射
```

### 渲染数据 (WorldWorker 返回)

```javascript
// Worker 返回的派生数据
{
  d: {
    "dirt": [x1,y1,z1, x2,y2,z2, ...],      // 每种类型的可见方块位置数组
    "grass": [...],
    ...
  },
  visibleKeys: ["x,y,z", ...],               // 所有可见方块键
  solidBlocks: ["x,y,z", ...],               // 实心方块键
  aoLow: { "x,y,z": 123456, ... },           // AO低位数据 (顶点0-11)
  aoHigh: { "x,y,z": 789012, ... }           // AO高位数据 (顶点12-23)
}
```

## 动态更新流程详解

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       玩家放置/删除方块流程                                   │
└─────────────────────────────────────────────────────────────────────────────┘

玩家操作: 放置方块
         ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  Chunk.addBlockDynamic(x, y, z, type, orientation)                         │
│                                                                             │
│  ① blockData[key] = {type, orientation}   ← 立即更新数据层                   │
│  ② solidBlocks.add(key)                   ← 更新碰撞集合                    │
│  ③ 创建单个 Mesh (动态网格)                 ← 视觉立即响应                    │
│  ④ 检查邻居方块，可能需要补面               ← 面剔除补丁                      │
│  ⑤ dirtyBlocks++                          ← 标记脏计数                       │
│  ⑥ scheduleConsolidation()                ← 调度合并                         │
└─────────────────────────────────────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  Consolidation 触发判断                                                      │
│                                                                             │
│  if (dirtyBlocks >= 50) {                                                  │
│    立即触发 consolidate()                                                   │
│  } else {                                                                   │
│    setTimeout(consolidate, 1000ms)  ← 防抖延迟                              │
│  }                                                                          │
└─────────────────────────────────────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│  ChunkConsolidation.consolidate()                                          │
│                                                                             │
│  ① 收集当前区块的 blockData                                                 │
│  ② 发送完整数据到 WorldWorker                                               │
│  ③ Worker: 重新计算面剔除 + AO                                              │
│  ④ Worker: 返回新的渲染数据                                                 │
│  ⑤ 主线程: 删除所有动态 Mesh                                                │
│  ⑥ 主线程: 清理旧 InstancedMesh                                             │
│  ⑦ 主线程: 重建新的 InstancedMesh                                           │
│  ⑧ 重置 dirtyBlocks = 0                                                    │
└─────────────────────────────────────────────────────────────────────────────┘
```

## AO 计算机制

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          AO (环境光遮蔽) 计算                                │
└─────────────────────────────────────────────────────────────────────────────┘

每个方块 6面 × 4顶点 = 24个 AO 值

┌─────────────┐
│   面顶点    │  每个角落检查3个邻居方块:
│             │
│  0───1     │  AO值 = 3 - (side1 + side2 + corner)
│  │   │     │
│  3───2     │  · side1: 侧面邻居是否遮挡 (0/1)
│             │  · side2: 另一侧面邻居是否遮挡 (0/1)
└─────────────┘  · corner: 角落邻居是否遮挡 (0/1)

AO 值范围: 0(最暗) ~ 3(最亮)

数据打包:
┌─────────────────────────────────────────────────────────────────────────────┐
│  aoLow (32位整数)                                                            │
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │ 顶点0 AO | 顶点1 AO | ... | 顶点11 AO  (每个占2位)                    │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  aoHigh (32位整数)                                                           │
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │ 顶点12 AO | 顶点13 AO | ... | 顶点23 AO  (每个占2位)                  │   │
│  └──────────────────────────────────────────────────────────────────────┐   │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 面剔除算法

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         面剔除 (Face Culling)                               │
└─────────────────────────────────────────────────────────────────────────────┘

方块 6面位掩码:
┌─────────────────────────────────────────────────────────────────────────────┐
│  TOP    = 0b000001  (Y+)                                                    │
│  BOTTOM = 0b000010  (Y-)                                                    │
│  NORTH  = 0b000100  (Z-)                                                    │
│  SOUTH  = 0b001000  (Z+)                                                    │
│  WEST   = 0b010000  (X-)                                                    │
│  EAST   = 0b100000  (X+)                                                    │
│                                                                             │
│  faceMask = TOP | BOTTOM | NORTH | SOUTH | WEST | EAST  (0-63)             │
└─────────────────────────────────────────────────────────────────────────────┘

判定规则:
┌─────────────────────────────────────────────────────────────────────────────┐
│  对于每个面，检查相邻位置的方块:                                             │
│                                                                             │
│  if (邻居是空气 || 邓居是透明方块) {                                        │
│    该面可见 → 渲染                                                          │
│  } else {                                                                   │
│    该面被遮挡 → 不渲染                                                       │
│  }                                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

跨区块处理:
┌─────────────────────────────────────────────────────────────────────────────┐
│  ┌───────────────┐     ┌───────────────┐     ┌───────────────┐             │
│  │   Chunk A     │────→│   Chunk B     │────→│   Chunk C     │             │
│  │               │     │               │     │               │             │
│  │ 边缘方块检查  │     │ 提供邻居数据  │     │ 提供邻居数据  │             │
│  │ 需要跨区块    │     │               │     │               │             │
│  └───────────────┘     └───────────────┘     └───────────────┘             │
│                                                                             │
│  createCrossChunkNeighborQuery(worldChunks) 支持跨区块查询                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

## InstancedMesh 渲染优化

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      InstancedMesh 批量渲染                                  │
└─────────────────────────────────────────────────────────────────────────────┘

传统方式 (N个方块 = N次 Draw Call):
┌─────────────────────────────────────────────────────────────────────────────┐
│  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐  ...  ┌─────┐                 │
│  │Mesh1│  │Mesh2│  │Mesh3│  │Mesh4│  │Mesh5│  ...  │MeshN│                 │
│  └─────┘  └─────┘  └─────┘  └─────┘  └─────┘  ...  └─────┘                 │
│     ↓        ↓        ↓        ↓        ↓    ...     ↓                     │
│  Draw1   Draw2   Draw3   Draw4   Draw5   ...  DrawN                      │
│                                                                             │
│  性能问题: N次 GPU 调用                                                     │
└─────────────────────────────────────────────────────────────────────────────┘

InstancedMesh 方式 (N个方块 = 1次 Draw Call):
┌─────────────────────────────────────────────────────────────────────────────┐
│  ┌──────────────────────────────────────────────────────────────────────┐   │
│  │                    InstancedMesh (dirt类型)                           │   │
│  │  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐  ...  ┌─────┐           │   │
│  │  │实例1│  │实例2│  │实例3│  │实例4│  │实例5│  ...  │实例N│           │   │
│  │  └─────┘  └─────┘  └─────┘  └─────┘  └─────┘  ...  └─────┘           │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│                              ↓                                              │
│                          1次 Draw Call                                      │
│                                                                             │
│  性能优化: 同类型方块批量渲染                                                │
└─────────────────────────────────────────────────────────────────────────────┘

按方块类型分组:
┌─────────────────────────────────────────────────────────────────────────────┐
│  ┌────────────────┐  ┌────────────────┐  ┌────────────────┐                 │
│  │ InstancedMesh  │  │ InstancedMesh  │  │ InstancedMesh  │                 │
│  │   (dirt)       │  │   (grass)      │  │   (stone)      │                 │
│  │  1000个实例    │  │  500个实例     │  │  800个实例     │                 │
│  └────────────────┘  └────────────────┘  └────────────────┘                 │
│         ↓                   ↓                   ↓                          │
│     Draw1               Draw2               Draw3                          │
│                                                                             │
│  总 Draw Calls = 方块类型数量 (而非方块总数)                                 │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 设计原则总结

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            核心设计原则                                      │
└─────────────────────────────────────────────────────────────────────────────┘

1. 单一数据源 (Single Source of Truth)
   ┌──────────────────────────────────────────────────────────────────────┐   │
   │  blockData 是唯一权威数据，所有其他数据都可从它派生                     │   │
   │  · 渲染数据 → 可重建                                                   │   │
   │  · AO 数据 → 可重算                                                   │   │
   │  · 面剔除 → 可重算                                                    │   │
   └──────────────────────────────────────────────────────────────────────┘   │

2. 异步合并优化
   ┌──────────────────────────────────────────────────────────────────────┐   │
   │  动态操作 → 立即响应 (单个 Mesh)                                        │   │
   │  批量合并 → 延迟执行 (InstancedMesh)                                   │   │
   │  平衡: 响应速度 vs 渲染性能                                             │   │
   └──────────────────────────────────────────────────────────────────────┘   │

3. Worker 并行计算
   ┌──────────────────────────────────────────────────────────────────────┐   │
   │  重计算任务 → Worker (不阻塞主线程)                                     │   │
   │  渲染创建 → 主线程 (Three.js API 要求)                                 │   │
   └──────────────────────────────────────────────────────────────────────┘   │

4. 数据不可变原则
   ┌──────────────────────────────────────────────────────────────────────┐   │
   │  Worker 返回的是新数据，不是修改现有数据                                │   │
   │  合并时是替换，不是增量更新                                             │   │
   └──────────────────────────────────────────────────────────────────────┘   │
```
